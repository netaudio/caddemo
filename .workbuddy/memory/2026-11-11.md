## ScanPro CAD 绘图模块：第一步 UI 界面完成

- 需求：按参考图（ScanPro V6.0.0「CAD绘制」页）用 C++ / Qt 6.7.3 实现桌面客户端 UI，用指定 CMake 做工程管理；后续再做 C/S 绘图功能。
- 环境：C:\Qt\6.7.3 只装了 msvc2019_64 套件；采用 "Visual Studio 16 2019" x64 生成器（MSVC 14.29）；CMake 为 D:\cmake-4.3.4-windows-x86_64\bin\cmake.exe；CMake POST_BUILD 调 windeployqt 部署 Qt DLL。
- 工程结构：CMakeLists.txt、build.bat、src/main.cpp、src/client/{MainWindow,RibbonBar,CadCanvas,CadIcons}.{h,cpp}、src/common/CadProtocol.h（C/S 共享命令/图元结构预留，server 尚未实现）。
- UI 还原：无边框自绘标题栏（Logo/快速访问/标题/窗口按钮）+ 8 个选项卡（开始/扫描/图像/测量/工具/选项/CAD绘制/超声卡）+ 7 个 Ribbon 组（文档/绘图/编辑/工具/视图/特定功能/当前属性）+ 左侧「探头库」竖排标签 + 中央 X-Z 绘图区（Z 轴红、工件五竖线轮廓）+ 右侧可折叠「盘面/平面扫查计划定制」面板 + 底部命令/坐标状态条。所有图标由 QPainter 程序绘制，无外部资源；QSS 采用 Office 2007 浅蓝风格。
- 交互占位：按钮、属性下拉框、键盘输入只更新状态条提示，绘图算法留待下一步。
- 验证：Release 编译通过；`caddemo.exe --screenshot <png>` 可无人值守抓图，`--selftest` 可模拟点击/切页/折叠做冒烟测试。预览图在 preview/。
- 坑：Qt6 中 `name == QLatin1String("CAD绘制")` 因中文 UTF-8 字节按 Latin1 解释恒为 false，必须用 QStringLiteral；否则选中页会错误显示占位页。
- 后续待办：绘图命令与图元渲染、DXF/Part2D 文件读写、智能导航与辅助栅格、右键结束命令、C/S 服务端与通信协议落地。
